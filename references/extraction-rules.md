# Extraction Rules — 채굴 8종 키워드 사전·시그널 패턴

> 채굴 단계 로딩. 발화쌍에서 8종 항목 식별·추출 규칙.

---

## 1. 결정/판단

**시그널:**
- 어미: "~하기로", "~로 한다", "확정", "결정"
- 부사: "최종", "결국"
- 챗지피티 응답 헤더: "✅ 결론·1줄", "🎯 결론"

**예시:**
- "5월에 파일럿 확정"
- "Creator/Explorer 2트랙으로 분리"
- "AI 결과 3단계 개선 루프 도입"

**태그:** `[t=N] 결정: ...`

---

## 2. 사실/수치

**시그널:**
- 숫자 + 단위 (만·억·조·%·명·일·주·월·년)
- 날짜 (YYYY-MM-DD, "5월", "7월 말")
- 고유명사 (회사명·인물명·제품명)
- 통계·범위 ("60~70%", "약 N억")

**예시:**
- "60명 × 480만 = 2.88억"
- "전 세계 학교 2~3만 개, 시장 7~14조원"
- "CAC/LTV 3면 차별화"

**태그:** `[t=N] 수치: ...`

**⚠️ 검증 필요:** 수치는 fact-checker 발동 후보

---

## 3. 미결/질문

**시그널:**
- 물음표 (?)
- 어미: "고민", "확인 필요", "미정", "검토 필요"
- 챗지피티 응답: "⚠️ 맹점·VARIABLE"

**예시:**
- "입시 연결 가능한가? (미결)"
- "교사 확보 어떻게?"
- "타겟이 교육 철학형 부모인지 성과 중심 부모인지"

**태그:** `[t=N] 미결: ...`

---

## 4. 아이디어/가설

**시그널:**
- 가정: "만약", "~할 수도", "~하면 어떨까"
- 제안: "~는 어떨까", "~을 시도해보자"
- 챗지피티 응답: "🚀 해결 구조", "💡 핵심"

**예시:**
- "Fake Proof → Seed Proof → Real Proof 3단계"
- "Humanity → AI → Output 지배구조"
- "KISAS Teacher Academy 모델"

**태그:** `[t=N] 가설: ...`

---

## 5. 액션

**시그널:**
- 명령형: "~해야", "~하자", "~만들자"
- 동사 명사화: "촬영·편집·배포"
- 챗지피티 응답: "📌 실행", "📌 바로 실행 액션"

**예시:**
- "10명 파일럿 → 3일 캠프 촬영"
- "Before/After 영상 5개 제작"
- "라텔 임무 7종 매핑"

**태그:** `[t=N] 액션: ...`

---

## 6. 번복/폐기

**시그널:**
- 부정: "아니다", "다시", "취소"
- 보정 요청: "~다시 해줘", "~말고"
- 새 결정이 앞 결정과 충돌

**탐지 알고리즘:**
```
for t in 발화쌍:
    new_decision = t의 결정 항목
    for prev_t in 이전 발화쌍:
        prev_decision = prev_t의 결정 항목
        if 같은 토픽 AND 충돌:
            mark prev_t as 번복 폐기
            mark new_t as 번복 후 결정
```

**예시:**
- t5: "6주 1사이클" → t8: "5월/7월말/8월 고정" → t5 번복
- t10에서 "전체갈이"로 했다가 t12에서 "최소 절개"로 회귀

**태그:** `[t=N] 번복: 이전 결정 X → 새 결정 Y`

---

## 7. 메타 이벤트

**시그널:**
- 형식 지시: "답변 ~지마", "~로 써줘", "왜 ~안해?"
- 톤 변경: "더 짧게·길게·구체적으로"
- 사용자가 응답 자체에 코멘트

**예시:**
- "내 채팅으로 저장 답변하지마"
- "왜 답변 끝에 새로운 제안 안해?"
- "이 수준이야?" (응답 품질 항의)

**태그:** `[t=N] 📍 메타: ...`

**처리:** 콘텐츠와 분리. 별도 트랙으로 박제.

---

## 8. 압박 회귀

**시그널 (복합):**
- 같은 토픽 N회 등장 (N ≥ 3)
- 짧은 추궁 메시지 ("??·다시·진짜?·왜?")
- 매 회귀마다 응답 깊이 증가

**카운트 알고리즘:**
```
topic_count = {}
for t in 발화쌍:
    for topic in t.topics:
        topic_count[topic] += 1

압박 토픽 = [topic for topic, count in topic_count.items() if count >= 3]
```

**예시 (사례3):**
- 토픽 A "사업 진단": t1 → t6 → t8 → t9 (4회 압박)
- 토픽 C "융합 본질": t3 → t4 → t5 (3회 압박)

**태그:** `[t=N] 🔁 회귀: 토픽 X (N번째)`

**처리:** 압박 회귀 타임라인 별도 섹션.

## 자동화 보조 정규식

**파일 위치:** `scripts/extract.py` (선택, 미구현)

**핵심 정규식:**
- 숫자: `\d+(?:[.,]\d+)?(?:억|조|만|%|명|일|주|월|년)?`
- 날짜: `\d{4}[-/]\d{1,2}[-/]\d{1,2}|\d+월(\s*말|\s*초|\s*중)?`
- 발화쌍: `^## (Prompt|Response):`
- 첨부: `\[Attachment:\s*([^\]]+)\]`
- 자기태깅: `확신도:\s*\d+\s*\([^)]+\)`

## 다중 태깅 예시

한 발화쌍이 여러 채굴 항목 가짐 = OK:

```
[t=8] 사용자: "5월에 파일럿, 7월말 캠프, 8월 LTV로 구체화"
[t=8] 응답:
  - 결정: 5월/7월말/8월 일정 고정
  - 수치: 60명, 480만원, 2.88억
  - 액션: 라텔 임무 7종 매핑
  - 번복: 이전 "6주 1사이클" 폐기
```

→ 4개 태그 동시 부여.
