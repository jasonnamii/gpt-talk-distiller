# Pattern Router — 4패턴별 처리 절차

> 패턴 분류 직후 로딩. 4패턴별 처리 방식·체크리스트·함정 정리.

---

## 패턴 분류 알고리즘 (재확인)

```
1. 발화쌍(Prompt-Response) 전부 인덱싱 → t1, t2, ..., tN
2. 각 발화쌍에서 토픽 라벨 후보 추출 (명사·고유명사·의도)
3. 토픽 회귀 카운트 (같은 토픽이 N회 등장)
4. 사용자 메시지 길이 vs 응답 길이 비율 측정

분기:
- N == 1 AND user_len > resp_len × 2  → 메모리주입형
- max_topic_recur ≥ 3                  → 반복압박형
- topic_count ≥ 3 AND recur 1~2회      → 점프형
- else                                 → 점진심화형
```

---

## 패턴 1 — 점진심화형 (Progressive Deepening)

**특징:**
- 단일 주제·단계적 발전
- 번복 0~1회
- 발화쌍 5~15개 일반적
- 사용자 메시지가 점점 구체화됨 ("타임라인 다시" 같은 보정)

**처리 절차:**
1. 토픽 1개로 통합 (또는 큰 토픽 2~3개)
2. 시간순 단계별 정리
3. 단계마다 백본 1줄 도출
4. 번복 발생 시 별도 타임라인 섹션
5. 최종 결정 = 가장 마지막 비폐기 결정

**출력 강조:**
- 번복 타임라인 (있을 때)
- 단계별 진화 흐름
- 최종 결정 압축

**함정:**
- 번복을 "최종"만 남기고 버리지 말 것 → 사고 흐름이 증거
- 단계 간 연결 서사 누락 ✗

## 패턴 2 — 점프형 (Topic Jump)

**특징:**
- A → B → A 회귀
- 토픽 3개 이상
- 메타지시 빈번 ("저장하지마"·"형식 바꿔")
- 짧은 발화쌍 (4~8개)

**처리 절차:**
1. 토픽 자동 분류 (3~5개)
2. 토픽별 발화쌍 재배치 (시간순 보존)
3. 회귀 마크 (A → B → A 표시)
4. 메타이벤트 별도 트랙
5. 교차 토픽 인사이트 도출

**출력 강조:**
- 토픽 회귀 표시
- 메타이벤트 분리
- 교차 토픽 인사이트

**함정:**
- "계속해줘" 같은 빈 메시지 → 응답 콘텐츠로 채굴
- 메타이벤트를 콘텐츠에 섞지 말 것

---

## 패턴 3 — 반복압박형 (Repeated Pressure)

**특징:**
- 같은 토픽 3회 이상 회귀
- 짧은 추궁 메시지 ("??·이 수준이야?·다시·왜 안해?")
- 발화쌍 8개 이상
- 매 회귀마다 응답 깊이 증가

**처리 절차:**
1. 토픽별 회귀 카운트 (≥3회 토픽 우선)
2. 회귀 시점마다 응답 깊이 추적
3. 압박 신호 메시지 박제 (사용자 짧은 추궁)
4. 회귀 타임라인 = "왜 사용자가 납득 못했는지" 흐름
5. 최종 도달 결론 = 가장 깊은 응답

**출력 강조:**
- 압박 회귀 타임라인
- 매 회귀마다 깊이 변화
- 압박 신호어 보존 (??·이 수준이야?)

**함정:**
- 회귀를 "단순 반복"으로 처리 ✗ → 매번 깊이가 다름
- 짧은 사용자 메시지가 핵심 전환점

## 패턴 4 — 메모리주입형 (Memory Injection)

**특징:**
- 발화쌍 1개 (단일 라운드)
- 사용자 메시지가 길고 구조화됨 (수백~수천 줄)
- 응답이 압축 요약본
- "기억해줘"·"위 내용 정리" 류 지시

**처리 절차:**
1. 사용자 메시지 = 1차 자료로 보존 (절단 ✗)
2. 응답 = 압축본으로 별도 박제
3. 두 자료 비교 → 압축 누락 항목 추출
4. 압축 누락 검증표 생성

**압축 누락 검증표 형식:**

```
| 사용자 메시지 핵심 | 응답에 살아있나 |
|---|---|
| TAM 12.4조 / Workforce 560만 | ✅ 있음 |
| SAM 5.12조 / SOM 5,800억 | ❌ 누락 |
| 창업자 현금흐름 ₩20억 차입 | ❌ 누락 |
```

**출력 강조:**
- 사용자 메시지 본문 보존
- 응답 압축본
- 누락 검증표 (가장 중요)

**함정:**
- 다른 패턴처럼 토픽 재조립 시도 ✗ → 1차 자료 절단됨
- 누락 항목을 "응답에 있다"고 오판 ✗ → 정확히 매칭 검사
